Detailed Description

Represents the Ultimate Tic-Tac-Toe game board.

Manages both the 9 sub-boards (3x3 each) and the main meta-board that tracks which player has won each sub-board.

Updates the board with a player's move.

Parameters

Returns
true if the move is valid, false otherwise.
Parameters
movePointer to the move (9x9 coordinates mapped to sub-board/cell).
Returns
true if the move is valid and applied, false otherwise.

Validates:

  • Coordinates are within bounds
  • Move is in the current active sub-board (or any open if free choice)
  • Sub-board is not already won/drawn
  • Cell is empty

After a successful move, checks if the sub-board is won or drawn, and updates the main board accordingly.
